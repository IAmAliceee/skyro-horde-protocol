## Context
I need to decide how I want to use Generative AI while I work on Horde Protocol

## Decision
Generative AI won't be used for any purposes not included in the following exclusions:
- Brainstorming idea for how to write something or Unity documentation / C# documentation look up. Find functions and how to use them
- Explaining and finding a fix for an error that you cannot solve. No copy-pasting code directly, all code must be hand written.

## Outcome
- No use of Gen-AI means no issues with tweaking assets to be "just right" or find the "right prompt"
- Using Gen-AI for quickly finding a method you are looking for and how to use it slightly speeds up needing to try-and-test
- Small errors or a badly written word can be a simple fix AI can spot very quickly
- Not copy-pasting / Hand writing all code means you understand what it does much better, it uses the same principle as "You learn better by writing down". As well, it helps you spot simple mistakes like a deprecated Unity method or ways to simplify certain parts.
